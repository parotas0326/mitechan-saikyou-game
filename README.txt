ミテちゃんは最強だぜ！ SORA RC1.05 試作

【起動】
1. ZIPを展開
2. index.html を Safari / Chrome で開く
3. スマホは横持ち推奨

【操作】
スマホ：← → / Bジャンプ / Aパンチ / 必殺技
PC：← → または A D / Zパンチ / Xジャンプ / V必殺技

【RC1.05 修正】
- 必殺技を専用ボタン化した3ボタンUIを維持
- 3連パンチコンボ
- HP + POWER HUD、通常攻撃ヒットでPOWER増加、MAXで必殺技
- 必殺技カットイン + SE
- 青龍の頭を進行方向の先頭に固定し、ミテちゃんの向きと完全同期
- 青龍の移動速度を低速化
- ヤンキー / 忍者 / 混成戦 / どんぐり攻撃 / 人馬おじさんを実装
- 1面ボス：ダイチ登場カットイン
- 2面を実装
- 2面ボス HP12
- 2面ボスは頭限定ダメージを廃止し、全身どこでも通常攻撃1ダメージ
- 2面ボスへの必殺技は全身どこでも3ダメージ
- 2面ボスの地面叩き攻撃
- 2面ボスは右側、ミテちゃんは左側の固定ボス画面
- 2面ボスカットイン「お前に戦争がとめられるのか！？」を別テキスト重ねで必ず全文表示
- 1面・2面ボス撃破時「げーむくりあ！」 + クリアSE
- GAME OVERを「ミテちゃんはまだ負けてない！」へ変更
- CONTINUEボタン追加（現在ステージの最初から）
- iPhone横持ち / マルチタッチ / PC操作対応
