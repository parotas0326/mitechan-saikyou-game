ミテちゃんは最強だぜ！ SORA RC 1.03

RC1.02からの主な変更
- ミテちゃんのキックを削除。操作は A=パンチ / B=ジャンプ / 必=必殺技 の3ボタン。
- 通常パンチ3連コンボ、POWER 10ヒットでMAX、必殺技専用ボタンは維持。
- 必殺技カットイン後、青龍波の向きを修正。手元が尻尾側、進行方向が龍の頭側になる。
- ダイチ登場を画像カットイン「DAICHI 参戦」に変更。
- ダイチは予備動作→パンチ/キック→戻りが読みやすいように演出を強化。
- 青龍波を受けたダイチは白フラッシュ＋大きなのけぞり＋青い被弾リング。
- ジャージ男は輪郭を強化し、常時不透明。被弾時のみ白フラッシュ。
- どんぐり忍者の弾を、大きくて明確などんぐり形状に変更。低い軌道を維持。
- 人馬おじさんは 人馬だけ高速タックル→その後おじさん単体で近接パンチ の二段構成。
