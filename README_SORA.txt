ミテちゃんは最強だぜ！ SORA RC 1.01 COMBAT TUNE

実機テストのフィードバックを反映した版です。

主な変更:
- ヤンキー描画時の半透明化を廃止。被弾時は白フラッシュに変更。
- どんぐりを大型化・輪郭強化・速度を155px/sへ調整。「どんぐり!」表示を追加。
- 人馬おじさんを再設計。
  1) 人馬おじさん登場
  2) 下の人馬だけ高速タックル
  3) タックル終了後、上のおじさんが通常近接敵としてパンチ
- A/B同時押し必殺技を廃止。
- Cボタン=キック、必ボタン=必殺技を追加。
- PC: Zパンチ / Xジャンプ / Cキック / V必殺技
- POWER MAX時に必殺技ボタンが発光。
- 必殺技発動前に青いチャージリング演出を追加。
- ハイパーウルトラ青龍波を旧版の約1/4速度(108px/s)に変更。
- ボスが必殺技を受けた際、白フラッシュ・強めノックバック・長めヒットストップ。
- ボス登場時にWARNING/BOSS登場の専用UI演出を追加。
- ボスのパンチ/キック予兆表示と攻撃エフェクトを明確化。
- ボス画像の背景/余計な隣接パーツを透明化。

POWER:
通常攻撃またはキックのヒット1回につき10。
10ヒットでMAX。必殺技使用後0へ戻ります。

RC1.02: ハイパーウルトラ青龍波の発動前に専用カットイン画像と効果音を追加。カットイン中はゲーム進行を一時停止し、その後にチャージ→青龍波発射。
