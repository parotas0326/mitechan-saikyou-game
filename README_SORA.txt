ミテちゃんは最強だぜ！ — SORA RC 0.98

完成直前の実機確認用ビルドです。

操作
- スマホ：左側 ← → / 右側 B=ジャンプ A=パンチ
- PC：← → または A/D、Z=パンチ、X=ジャンプ
- タイトル：GAME START部分を含むゲーム画面をタップ、またはA/B

収録
- 夜の商店街 横スクロール
- ヤンキー / どんぐり忍者 / 人馬おじさん / JLボス
- HP、スコア、ステージ進行、ボスHP
- HIT/被弾/攻撃予兆/ゲート/SE
- GAME OVER / STAGE CLEAR / リトライ

方針
実機テスト回数を減らすため、ゲーム進行と操作の一通りを先に統合しています。
次はiPhone横持ちで最後までプレイし、表示・難易度・ボタン位置などの修正点をまとめて調整する想定です。
